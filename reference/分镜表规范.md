# 分镜表规范（storyboard json 块）

**FROZEN @ CONTRACT 2026-06-20**（镜像平台 `shot_agent/tools/storyboard.py` 的
`validate_storyboard`；`export.py` 内置的 `validators.validate_storyboard` 即此规则）。

每集 `episodes/E{n}.md` 的 `## 分镜表` 段含**一个** json 围栏块，结构为
`{"title", "shots":[], "shot_groups":[]}`。校验**全过才写盘**。

---

## 1. 顶层

- `title`：本集分镜标题，**非空**。
- `shots`：镜头数组，**非空**。
- `shot_groups`（叙事组）：分组数组，**非空**。

## 2. shot 必填字段（`REQUIRED_SHOT_FIELDS`）

```
shot_id  shot_number  scene  shot_type  action_desc  duration  group_id
```

- 任一字段缺失或为 `None` / `""` → 报 `shots[i] 缺字段 X`。
- `shot_id` 在全表内**唯一**；重复 → 报 `shot_id 重复`。
- 可选增强字段（平台读、export 透传）：`characters`、`dialogue`、`camera_movement` 等。
  - **`dialogue`**：对白数组，有台词时填写；`export.py` 据此自动生成 `video_prompt` 的 `对白：` 段（见 `reference/提示词规则.md §2.5`）。
    格式：`[{"speaker": "角色名", "text": "台词原文", "emotion": "情感标签"}]`
    - `speaker`：说话人，与圣经角色**短名**一致（不带括号描述）
    - `text`：台词完整原文，与剧本结构化对白一致
    - `emotion`：情感/语气标签，供平台 TTS 克隆参考（如 `"紧张"` / `"激动"` / `"平静"` / `"哽咽"` / `"冷淡"`）
    - 无台词镜头：省略字段或写 `[]`，`export.py` 不追加 `对白：` 段
    - 多说话人：数组含多个对象，按台词顺序排列
- **推荐双语运动提示词**（强烈建议每镜都写，规则见 `reference/提示词规则.md`）：
  - `video_prompt`（中文，三段，段头须含 `画面：/运镜：/音效：`）；
  - `video_prompt_en`（英文，自由文本运动描述）。
  二者并存：平台按项目 `config.json` 的 `video_prompt_lang∈{zh,en}` 取用，写齐即两种语言都覆盖。

> 说明：`video_prompt` 在**平台分镜生成时**强制（zh 查三段头）；`export` 为保「全集可见 /
> 渐进创作不阻塞」**不硬校验**，只在报告里**软提醒**哪些写了 shots 却缺 `video_prompt`
> （缺则平台出视频回退 `action_desc`，运动表现打折）。`action_desc` 写静态可拍画面，
> `video_prompt` 写时间维度运动——分工别混，详见 `reference/提示词规则.md`。

## 3. shot_group 必填字段（`REQUIRED_GROUP_FIELDS`）

```
group_id  relation  shot_ids
```

- 任一缺失或为 `None` / `""` → 报 `shot_groups[i] 缺字段 X`。

## 4. relation 枚举（`ALLOWED_RELATIONS`）

```
montage  progressive  causal  contrast  single
```

非法值 → 报 `shot_groups[i] relation 非法: ...`。

## 5. 叙事组 ↔ 镜头 交叉引用规则

- **每个 shot 必须归属某叙事组**：`shot.group_id` 必须能在某个 `shot_groups[*].group_id`
  里找到，否则报 `shots[i] 未归属任何叙事组 group_id=...`。
- **叙事组不得引用不存在的镜头**：`shot_groups[*].shot_ids` 里的每个 id 必须是真实存在
  的 `shot.shot_id`，否则报 `shot_groups.shot_ids 含 shots 中不存在的镜头: [...]`。

---

## 6. 范例（与 `example/manuscript/episodes/E1.md` 一致）

```json
{"title": "停摆的钟", "shots": [
  {"shot_id": "s1", "shot_number": 1, "scene": "钟楼", "shot_type": "wide", "action_desc": "林夏推门,逆光剪影", "duration": 4.0, "group_id": "g1", "characters": ["林夏"], "dialogue": []},
  {"shot_id": "s2", "shot_number": 2, "scene": "钟楼", "shot_type": "close-up", "action_desc": "齿轮背面血字特写", "duration": 3.0, "group_id": "g1", "characters": [], "dialogue": []}],
 "shot_groups": [{"group_id": "g1", "relation": "progressive", "shot_ids": ["s1", "s2"], "name": "发现"}]}
```

- 两个 shot 都归属 `g1`（`group_id` 命中叙事组）；
- `g1.shot_ids = ["s1","s2"]` 全部指向真实 shot；
- `relation = "progressive"` 在枚举内 → 校验通过，0 错。

---

## 7. 可选字段:extra_refs(分镜出图参考锚)

`shot_group` 可加 `extra_refs`:资源 key 字符串数组(形如 `"scene/宿舍"`、`"prop/手机"`),
列出本组分镜出图时**额外参考**的场景/道具锚图。平台 `grid_gen` 出图时把这些锚图加进参考图
(角色锚+画风锚之外)。仅 `scene/*`、`prop/*` 生效;缺图跳过不阻塞。`export` 透传,
`validate_storyboard` 不拦(可选字段)。范例:

```json
{"group_id": "g1", "relation": "progressive", "shot_ids": ["s1","s2"], "extra_refs": ["scene/宿舍", "prop/手机"]}
```

> 平台 UI(叙事组检视「分镜参考锚图」勾选区)写这个字段;手稿作者也可直接在分镜表 json 块写。
