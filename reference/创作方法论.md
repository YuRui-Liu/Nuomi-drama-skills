# 创作方法论(自包含 · 蒸馏自平台宪章与批判环)

**镜像自平台 `shot_agent/constitution/principles/*.md` + `constitution/panel.py` 批判环判据 + `axes/builtin/tones/vocabulary.md` @ 2026-06-20。**
本文件是 skill 的方法论单一事实源,**不依赖 repo 外部文件**。各阶段先读对应小节再写。

## 一、各阶段创作宪章(精要)
- **立意(ideation)**:三轴正交(题材×风格×基调);能压成一句控制理念「生活变成X,当主角做Y,因为Z」;基调是高杠杆上游件,必进批判环。
- **大纲(outline)**:每集有钩子 + ≥1 组爽点节拍;集间冲突总体递增(可憋屈—爆发波浪,不长段递减);集内/系列首尾押韵。
- **剧本(script)**:①忠于立意 ②每场有功能(推进冲突 OR 揭示人物,无闲场)③钩子前置 ④节奏张弛 ⑤人物一致 ⑥**严格遵 `reference/剧本格式规范.md` 结构**。只写镜头拍得到的(动作动词+在场对象,禁内心活动/情绪形容词)。
- **分镜(storyboard)**:schema 合规;按叙事节拍分组;忠于剧本;基调兑现(镜头节奏/景别密度);可拍可出图(action_desc 谁/在哪/做什么/景别);video_prompt 只写运动。
- **视频(video)**:首帧锚定;global_prompt 统一风格;single≤组、单段时长护栏;失败必复盘、如实汇报(平台阶段,创作侧只需 video_prompt 写好)。
- **基调(tone)**:情感温度/叙事节奏/动作密度等档位;终局须兑现开篇承诺的情绪(爽感兑现/情绪闭环)。

## 二、批判环判据(逐阶段自检 rubric · 镜像 panel.py)
**剧本**:
- `logic` 故事逻辑因果:自洽无降智、每场以「因为」承前 N-1,非「然后」时序堆叠。
- `character` 人物一致:贴合该角色弧光/认知状态(谁知道什么)。
- `pace` 节奏与爽点:符合题材爽点权重与钩子密度,开篇+集尾钩子到位;情绪+/−交替振幅渐增。
- `foreshadow` 伏笔推进:按本集计划开窗/回收,无凭空回收未埋之物(契诃夫之枪)。
- `dialogue` 对白质量:自然、有信息量、符合人物口吻,无水词、无 info-dump、无复述画面。
- `format` 格式合规:严格遵剧本格式规范(见 checklist)。
- (高杠杆)**价值翻转**:每场翻转一个价值(信任↔背叛/控制↔无力/希望↔绝望…),标入场态→出场态;本集≥1 次高幅翻转(打脸/逆袭/认知双击)。无翻转判废场(删场测试:删掉本集钩子/爽点/伏笔链断不断)。

**分镜**:
- `shot_narrative` 镜头叙事性:每镜服务剧情与情绪,非堆砌。
- `shootable` 可拍可出图:景别/动作具体可执行。
- `grouping` 叙事组与节奏:见下「叙事组方法论」。
- `style` 风格兑现:画面提示与三轴风格一致。
- `dialogue_placement` 台词归位:对白落到正确镜头的 dialogue。
- `video_prompt` 只写运动:见 `reference/提示词规则.md`。

## 三、三轴 / 基调词表(精要)
- 三轴:题材(genre)× 风格(style,平台内置 style_id)× 基调(tone)。基调入批判环——跑偏会污染下面每一集。
- 基调档位示例(情感温度):炽热 / 温暖 / 克制 / 冷峭 / 外冷内疯…;叙事节奏:舒缓 / 中速 / 快板 / 强冲击。基调 arc(弧光):觉醒型 / 清醒破局型 / 救赎型…
- 基调要写得**可被下游推导**(见「五、音频上游」:情感温度→配乐情绪/调式,叙事节奏→bpm)。

## 四、叙事组分镜方法论
- 每个 shot **恰归属一个**叙事组;每组=**一个叙事节拍**;组内 1–5 镜。
- `relation` 五值语义:`montage`(并列蒙太奇)/`progressive`(递进)/`causal`(因果)/`contrast`(对比反差)/`single`(单镜独立)。按组内镜头的真实关系选。
- 叙事组划分服务节奏:一个动作单元/一次情绪转折=一组;勿把无关镜头塞一组,勿一镜一组碎成流水账。

## 五、音频上游方法论(skill 只产上游,音频产物全平台生成)
平台从 skill 的上游产物**自动推导**音频提示词,故把上游写好即可,**不要**在手稿里写 `audio_cues.json`/`voices.json`/BGM tags/真实合成:
- **基调 → ace-step 配乐**:平台 `bgm_gen` 据 `基调.情感温度`(→情绪/调式/乐器 tags)+ 题材 + `叙事节奏`(→bpm 档位)推导 ACE-Step tags/bpm。⇒ 立意写基调时,按"可映射情绪/调式/速度"来定。
- **角色声音 → qwen3-tts 音色**:平台音频设计阶段产 `voices:[{character,voice_style,language}]`,qwen3-tts 据 style 设计音色。⇒ 圣经 `角色.声音`(语域/音色/口头禅/独特称呼)按"可设计成稳定、跨集一致的音色"写。
- **剧本神态 / 台词情感 → TTS 克隆**:平台据台词+情感(IndexTTS2 克隆)出配音。⇒ 结构化剧本 `**角色名**（神态/语气）：台词` 的括注、storyboard `dialogue` 的情感,就是 TTS 情感种子,要写准。
- **边界**:skill 产**基调 / 角色声音 / 神态 / 台词**;配音/配乐/SFX/混音/成片**全部平台生成**。
