# 剧本格式规范(结构化剧本 · 冻结镜像)

**镜像自平台 `shot_agent/constitution/principles/script.md` 原则6 + `panel.py` SCRIPT_CRITICS.format @ 2026-06-19。**
平台编剧面板读 `E{n}/script.md`,分镜师据此拆分镜,故**剧本必须是下面的结构化 markdown,不能是自由散文**。

## 硬约束 checklist(逐条核对,任一不符即不合规)
- [ ] 集名首行恰为 `# 《剧集名称》第X集《本集标题》`(无本集标题时退化 `# 《剧集名称》第X集剧本`);X=本集集号,标题取自大纲本集 entry。
- [ ] 每场起头恰为 `## 第N场 地点·时间（日/夜）`;时间仅取 `日`/`夜`;N 从 1 递增。
- [ ] 每场含 `**本场人物**：` 与 `**场景描述**：` 两行;台词行恒为 `**角色名**（神态/语气）：台词内容`;动作段以 `【动作】` 起。
- [ ] 声音/脚步/环境音/音效一律写进 `【动作】`;**禁止**自创 `【音效】`/`【脚步声】`/`【环境音】`。
- [ ] 镜头/画面信息用 `【镜头/画面标注】`(不含音效);场末转场用 `【暗场】`/`【片名弹出】`/`【片尾曲起】`/`【灯黑】`。
- [ ] 场与场之间、全篇结尾前,用单独一行 `---` 分隔。
- [ ] 全剧以单独一行 `**【第X集完】**` 收尾,且为唯一收尾行,其后无 `---` 或任何内容。
- [ ] 无真人出场场景(空镜/蒙太奇/屏幕画面)`**本场人物**` 写「无」即可,不要求年龄/身份括注。

## 结构(逐字遵循)
```
# 《剧集名称》第X集《本集标题》
---

## 第N场 地点·时间（日/夜）
**本场人物**：角色A（年龄+身份/标签）、角色B（…）
**场景描述**：一句话讲清场地全貌。

【动作】走位/肢体/环境变化。
**角色名**（神态/语气）：台词内容

【镜头/画面标注】远景/近景/特写/转场/字幕/画外音(按需)

---

## 第N+1场 …
…

---
**【第X集完】**
```

> **神态括注=配音情感种子**:`（神态/语气）` 会被平台音频阶段当作 TTS 情感线索,要写准(详见 `reference/创作方法论.md` 音频上游)。
> action_desc(分镜)写静态可拍画面,与剧本 `【动作】` 分工:剧本是给人读的场本,分镜是给出图/出视频的镜头表。
