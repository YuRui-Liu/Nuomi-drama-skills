## 2. 出图管线本质

`shot_agent.pipeline.imagegen.run_imagegen()` 是一个 **LLM Agent 驱动的交互式管线**，分为三段：

1. **段① 角色锚点**：用 `generate_anchor_images` 为主要角色出定妆图 → 人工确认
2. **段② 画风锚**：出第一个叙事组的宫格图作为风格锚 → 人工确认
3. **段③ 逐组出图**：遍历所有叙事组 → 每组出宫格 → 拆图归一化 → 超分 → 落位 → 人工汇报

**关键特性**：
- 每段结束后有个 `await_human` 卡点，要求用户确认或打回重做
- 这意味着它不能在无交互的自动化脚本中直接使用
- Group 是原子单位：同组所有镜一起出成宫格图再拆开

## 3. 可用替代方案

### 3a. 诊断出图状态（无需 provider/API）

```python
from pathlib import Path
import json

project_dir = Path("out/E1")
ctx = json.loads((project_dir / "gen_context.json").read_text(encoding="utf-8"))
sb = ctx.get("storyboard", {})
shots = sb.get("shots", [])
groups = sb.get("shot_groups", [])

assets_dir = project_dir / "shots_assets"
grids_dir = project_dir / "imggen/grids"

for g in groups:
    gid = g["group_id"]
    grid_path = grids_dir / f"group_{gid}.png"
    g_shots = [s for s in shots if s.get("group_id") == gid]
    print(f"{gid} ({g['name']}): "
          f"{'✓' if grid_path.is_file() else '✗'} grid | "
          + " | ".join(f"{s['shot_id']}={'✓' if (assets_dir/f'{s['shot_id']}.jpg').is_file() else '✗'}"
                       for s in g_shots))
```

### 3b. 启动 GUI 服务器

cd nuomi-drama-agent-lab

### 3d. generate_log.json 使用

```bash
# 查看所有失败记录
cat out/generate_log.json | python -c "import sys,json; [print(json.loads(l)) for l in sys.stdin]"

# 按集统计失败
cat out/generate_log.json | python -c "
import sys, json
failures = {}
for l in sys.stdin:
    r = json.loads(l)
    ep = r.get('ep')
    failures.setdefault(ep, []).append(r['shot_id'])
for ep, shots in sorted(failures.items()):
    print(f'E{ep}: {len(shots)} fails — {shots}')
"
```

## 4. Grsai/RunningHub 常见失败模式

| 错误信息 | 可能原因 | 对策 |
|---------|---------|------|
| "violate our content policies" | 提示词触发了 Grsai 的安全策略（暴力/血腥/政治敏感） | 修改 action_desc/video_prompt，弱化可能敏感的措辞 → re-export → 重试（新 provider 或修改 prompt） |
| "guardrails around violence" | 同上，更明确指向暴力描写 | 用"能量爆发""灵力冲击"替代"血/杀/斩"等字眼 |
| timeout / 无响应 | RunningHub 队列满或网络问题 | 重试 |
