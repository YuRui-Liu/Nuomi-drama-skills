# 自定义题材 YAML 创作指南

当你的故事不在内置题材列表中时，需要创建一个自定义题材 yaml 放在 `manuscript/genres/<id>.yaml`。export.py 会自动拷进 `project/genres/`，平台优先读取项目级题材。

## 必填字段

```yaml
genre_id: your-unique-id           # 小写字母+连字符，00_立意.md 中 genre_id 引用此值
display_name: 中文显示名            # 平台 UI 显示用
```

## 核心结构字段

| 字段 | 类型 | 必填 | 用途 |
|------|------|:----:|------|
| `core_conflict` | list[str] | ✅ | 题材的核心冲突类型，供创作时保持冲突聚焦 |
| `satisfaction_types` | list[str] | ✅ | 题材的爽点类型，供大纲阶段设计爽点节拍 |
| `taboos` | list[str] | ✅ | 此题材的禁忌/反模式，引导创作者的边界感 |
| `typical_setup` | str (YAML \|) | 推荐 | 典型开场描述（多行字符串），给新项目提供起点 |
| `target_audience` | dict | 推荐 | 目标受众画像（年龄/性别/标签） |
| `recommended_episodes` | dict | 推荐 | 推荐集数范围及单集时长（`min`/`max`/`typical`/`unit_duration_sec`） |
| `overseas_mapping` | dict | 可选 | 出海映射（目标市场/译名/平台适配） |
| `writing_rules` | list[str] | 可选 | 写作规则（特殊题材如反诈/教育类必须） |
| `donts` | list[str] | 可选 | 禁止项独立字段，taboos 的补充 |

## 字段设计原则

### `core_conflict` — 给编剧看的冲突燃料

列出 4-6 个该题材最核心的冲突对，格式 `"X vs Y"`：

```yaml
core_conflict:
  - 资源匮乏 vs 团队生存需求
  - 人性底线 vs 末日道德崩坏
```

这些是大纲阶段设计"每集钩子"和"爽点节拍"的参考源。每个冲突都可以衍生出若干集的核心矛盾。

### `satisfaction_types` — 爽点库

列出该题材最有效的爽点类型，每个 4-8 个字：

```yaml
satisfaction_types:
  - 绝境反杀
  - 真相揭晓
  - 视觉奇观
  - 感人牺牲
```

批量产集时从这些类型里选配到每集的爽点节拍。

### `taboos` / `donts` — 反模式清单

用"不要..."句式写该题材常见的坑：

```yaml
taboos:
  - 不要拖沓建置世界观——短剧用第一场快速代入
  - 不要让觉醒过程太容易——必须付出代价
```

export.py 不校验此字段——它是给 Claude 的创作约束，不是数据契约。

## 注意事项

- **genre_id 唯一性**：不要与内置题材 ID 重名（内置列表：`ceo-romance/commercial/counterattack/face-slap/mv/oral-skit/short-drama/single-episode/vlog/war-god-return/rebirth/time-travel/son-in-law/chase-wife/revenge/divine-doctor/system-rich/war-god/urban-xianxia/palace-intrigue/school-rising/group-pet`）
- **平台优先级**：项目级 > 平台级。同名时项目级覆盖平台内置，所以自定义题材建议用独特前缀命名避免冲突（如 `xianxia-awakening` 而非 `xianxia`）
- **yaml 编码**：文件名和内容保持 UTF-8，含中文。export.py 完整保留 yaml 内容

## 视觉风格引用

`00_立意.md` 的 `风格.style_id` 必须命中平台注册表。当前可用风格：

- `real/`：`cinematic-warm-v1`, `cinematic-cool-v1`, `doc-natural-v1`, `golden-hour-romance-v1`
- `2D/`：`anime-cel-v1`, `guofeng-ink-v1`, `ghibli-warm-v1`, `guofeng-gongbi-v1`
- `3D/`：`pixar-stylized-v1`, `photoreal-octane-v1`, `pixar-cute-v1`

风格选型建议：古装仙侠 → `2D/guofeng-ink-v1`（水墨）或 `2D/anime-cel-v1`（赛璐珞）；现代甜宠 → `real/cinematic-warm-v1`；玄幻 → `2D/guofeng-gongbi-v1`（工笔）
