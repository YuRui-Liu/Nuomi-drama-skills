# 立意:《作品名》

围栏外的正文即 `idea`(立意散文)。一句话讲清:在什么世界里、谁、要什么、
卡在哪、为何独特。三轴(题材×风格×基调)正交,基调必须进批判环。

下方 json 块承载三轴 + 模式 + 集数:`mode` = `series`(多集)或 `free`(自由);
`episode_count` = 大纲全 N 集。

**三轴必须命中平台 axes 注册表(否则平台导入报错;`export.py` 会软提醒):**
- `题材.genre_id`:内置题材之一(`ceo-romance/commercial/counterattack/face-slap/mv/oral-skit/short-drama/single-episode/vlog/war-god-return/rebirth/time-travel/son-in-law/chase-wife/revenge/divine-doctor/system-rich/war-god/urban-xianxia/palace-intrigue/school-rising/group-pet`),**或**自带自定义题材:把 `<id>.yaml` 放进 `manuscript/genres/`(export 会随项目拷进 `project/genres/`,打包后平台也能读)。
- `风格.style_id`:`real/{cinematic-warm-v1,cinematic-cool-v1,doc-natural-v1,golden-hour-romance-v1}` · `2D/{anime-cel-v1,guofeng-ink-v1,ghibli-warm-v1,guofeng-gongbi-v1}` · `3D/{pixar-stylized-v1,photoreal-octane-v1,pixar-cute-v1}` 之一。
- `基调.levels`:**四维全齐**(缺一即报「基调缺维度」),档位取自词表 ——
  `情感温度∈{冷峻,克制,温暖,炽热}` · `动作密度∈{纯文戏,文武均衡,强动作}` · `叙事节奏∈{舒缓,稳健,快切,高频反转}` · `主题深度∈{纯爽无负担,轻寓意,厚重思辨}`;
  `arc∈{成长型,觉醒型,救赎型,双向救赎,堕落型,悲剧型,坚守型}`。

```json
{"triplet": {"题材": {"genre_id": "single-episode", "display_name": "单集短篇"},
             "风格": {"style_id": "real/cinematic-warm-v1", "category": "real", "name_cn": "电影暖调"},
             "基调": {"levels": {"情感温度": "克制", "动作密度": "纯文戏", "叙事节奏": "稳健", "主题深度": "轻寓意"}, "arc": "觉醒型"}},
 "mode": "series",
 "episode_count": 1}
```
