## 分镜表

每个 `shot` 必备:`shot_id / shot_number / scene / shot_type / action_desc /
duration / group_id`。每个 `shot_group` 必备:`group_id / relation / shot_ids`。
`relation` 合法值:`montage / progressive / causal / contrast / single`。
所有 shot 的 `group_id` 必须能在某个叙事组中找到,叙事组的 `shot_ids` 也必须
全部指向真实存在的 shot。详见 `reference/分镜表规范.md`。

强烈建议每镜写**双语运动提示词**(规则见 `reference/提示词规则.md`):
`video_prompt`(中文三段,段头含 `画面：/运镜：/音效：`,只写时间维度运动)+
`video_prompt_en`(英文自由文本运动描述)。`action_desc` 写静态可拍画面,二者分工别混。
`dialogue` 有台词时写对象数组（speaker/text/emotion），`export.py` 自动追加为 `video_prompt` 的 `对白：` 段；无台词写 `[]`。

```json
{"title": "",
 "shots": [
   {"shot_id": "s1", "shot_number": 1, "scene": "", "shot_type": "wide",
    "action_desc": "(静态可拍画面:在场对象+动作)", "duration": 3.0, "group_id": "g1",
    "video_prompt": "画面：…。运镜：…。音效：…。",
    "video_prompt_en": "(english free-text motion)",
    "characters": ["角色名"],
    "dialogue": [{"speaker": "角色名", "text": "台词原文", "emotion": "情感"}]}],
 "shot_groups": [
   {"group_id": "g1", "relation": "single", "shot_ids": ["s1"], "name": ""}]}
```
