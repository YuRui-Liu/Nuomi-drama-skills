# 分卷节拍表

把全 N 集切成若干卷(arc),每卷一条目标 + 集号区间 + 节拍清单。
节拍纪律(`validate_beats` 会逐卷检查):
- `目标集` 必须落在本卷 `集` 范围内;
- `关联thread` 必须已在卷的 `threads` 里声明;
- `关联伏笔` 必须已在卷的 `伏笔计划` 里声明(按 `id`);
- 节拍按 `目标集` 单调递增(不许倒序)。

`伏笔计划` 钉每条伏笔的开窗集 / 回收集;`出场角色` 列本卷主要角色。

```json
{"arcs": [
  {"arc": 1, "目标": "", "集": [{"ep": 1}],
   "threads": ["T1"],
   "伏笔计划": [{"id": "F1", "开窗集": 1, "回收集": 1}],
   "节拍": [{"beat": "", "功能": "", "目标集": 1, "关联thread": ["T1"], "关联伏笔": ["F1"]}],
   "出场角色": []}]}
```
