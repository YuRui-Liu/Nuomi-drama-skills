# 大纲

整部作品的剧集大纲。`episodes[]` 必须覆盖全 N 集(与 `00_立意.md` 的
`episode_count` 一致)。每集必备字段:`ep / 标题 / 梗概 / 本集钩子 / 爽点节拍`
(钩子=本集结尾留扣;爽点节拍=本集情绪高点序列)。`出场角色 / 关键场景 /
上集衔接` 为可选增强字段。

```json
{"series_logline": "",
 "主线": "",
 "副线": [],
 "episodes": [
   {"ep": 1, "标题": "", "梗概": "", "本集钩子": "", "爽点节拍": [],
    "出场角色": [], "关键场景": [], "上集衔接": ""}]}
```
