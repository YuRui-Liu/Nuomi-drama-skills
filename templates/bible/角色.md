# 角色

每个角色一条,key 用短名(canonical id);括号描述只进 `aliases`,不进 key。
**规范化规则**:`export.py` 会自动把含括号描述的 key（如 `"林夏（钟表匠之女）"`）剥离为短名 `"林夏"`,括号部分自动进 `aliases`——作者直接写短名即可,写全名也不会出错。
`外貌` 是出图锚点,必须写实够细(发型/服饰/年代/神态/标志物)以便平台生成
一致的 anchor 参考图。`arc[]` 逐集记角色情感状态/处境/已知信息(可选、按需追加)。

```json
{"characters": {
  "林夏": {"身份": "", "外貌": "", "性格": "", "动机": "",
           "关系网": {}, "arc": [], "aliases": []}}}
```
