# 伏笔与线索

两张表:`foreshadows`(伏笔,逐条记埋设集/计划回收集/状态)与
`threads`(线索/暗线,逐条记涉及卷/当前进度/状态)。
这里的 id 必须与 `02_分卷节拍表.md` 中 `关联thread` / `关联伏笔` 引用一致,
否则 `validate_beats` 会拦。

```json
{"foreshadows": {"F1": {"描述": "", "埋设集": 1, "计划回收集": 1, "状态": "open", "相关人物": []}},
 "threads": {"T1": {"描述": "", "涉及卷": ["1"], "当前进度": "", "状态": "active"}}}
```
